# Omida Studio roadmap

## Available in 0.3

- Installer with automatic updates, and a portable ZIP.
- Chat with full Markdown, syntax highlighting, editing, regeneration, branches, system prompts, sampling controls, search, and image input.
- Workspace agent with paged reads, regex and glob search, file creation, command execution, per-change review, and revert.
- Automatic context sizing and conversation compaction.
- Benchmarks with repeated trials, noise-aware comparisons, and a graded quality check.
- Model discovery on Hugging Face with fit estimates that account for the context window.

## Next

- Code-sign the Windows builds.
- Compare two models or two quantizations of one model side by side in Benchmarks.
- Larger, task-specific quality suites, and token probability inspection.
- Several models loaded at once, and parallel requests.
- Hugging Face sign-in for gated models, and multi-part GGUF files.
- Wider validation on AMD and Intel graphics and on CPU-only PCs.

The order can change with testing and feedback. Requests and reproducible reports are welcome in [GitHub Issues](https://github.com/gh0st359/omida-studio/issues).
